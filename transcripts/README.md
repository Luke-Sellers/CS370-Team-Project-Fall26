# Transcripts

Raw Claude Code session files, copied in as-is. Not summarized, not
exported, not retyped.

Each partner copies their own, from their own machine, from their own
sessions:

    cp ~/.claude/projects/<this-project-dir>/*.jsonl \
       transcripts/<your-name>/

Do this at EVERY milestone (M1 through M5), covering the work since the
previous milestone. Local transcripts are purged after 30 days by
default and this project runs longer than that, so also raise
cleanupPeriodDays in your Claude Code settings now. A foreseeable loss
is not an excused one.

Work in a dedicated project directory so the copy stays a one-line cp.

Sessions are personal. Each partner works in their own clone, under
their own login. Process points are computed per partner from that
partner's own .jsonl files, corroborated against that partner's own
commits. One shared login costs both partners.
